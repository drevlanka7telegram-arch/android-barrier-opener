# ШлагбаумДревлянка7

Легковесное Android-приложение для автоматического открытия шлагбаума в районе Древлянка 7 (Петрозаводск) при въезде в геозону.

## Возможности

- **Ручное открытие**: проверка геолокации и звонок на номер шлагбаума с отправкой USSD-кода.
- **Авто-открытие (Геозона)**: автоматическое срабатывание при въезде в радиус действия (через Geofence API).
- **Настройки**: изменение номера телефона, USSD-кода, радиуса действия и координат шлагбаума.
- **История**: сохранение последних 10 открытий.

## Координаты по умолчанию

- **Широта**: 61.7513049 (61°45'04.7" с.ш.)
- **Долгота**: 34.3089593 (34°18'32.3" в.д.)
- **Адрес**: проезд Вьюжный, 10 (район Древлянка, Петрозаводск)

## Технологии

- Kotlin
- Google Play Services (Location, Geofence)
- Material Design Components
- Android Telephony API (для звонков и USSD)

## Как это работает (Авто-открытие)

1. Пользователь включает режим «Автоматическое открытие» в настройках.
2. Приложение запрашивает разрешение `ACCESS_BACKGROUND_LOCATION` (Android 10+).
3. В систему добавляется геозона (Geofence) с заданными координатами и радиусом.
4. При входе в зону срабатывает `GeofenceBroadcastReceiver`.
5. Запускается `GeofenceService` (фоновый сервис с типом `location`).
6. Сервис открывает `MainActivity` с флагом `auto_open=true`.
7. Приложение проверяет дистанцию и инициирует вызов шлагбаума + отправку USSD.

## Требуемые разрешения

- `ACCESS_FINE_LOCATION` — точная геолокация.
- `ACCESS_BACKGROUND_LOCATION` — работа в фоновом режиме (Android Q+).
- `CALL_PHONE` — совершение вызова.
- `READ_PHONE_STATE` — отслеживание состояния звонка для отправки USSD.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/drevlanka7telegram-arch/android-barrier-opener.git
   ```
2. Откройте проект в Android Studio.
3. Запустите на устройстве с Android 8.0 (API 26) или выше.

## Структура проекта

- `MainActivity.kt` — основной экран, логика проверки дистанции и звонков.
- `SettingsActivity.kt` — экран настроек (SharedPreferences).
- `GeofenceHelper.kt` — управление геозонами.
- `GeofenceBroadcastReceiver.kt` — приемник событий входа в геозону.
- `GeofenceService.kt` — фоновый сервис для обработки событий.
